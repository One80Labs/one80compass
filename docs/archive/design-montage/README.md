# One80Compass dashboard mockup

Source image: `One80Compass-dashboard-mockup.jpg`. The nine screens are the target look and the target information on each page. The shared frame is a white left navigation, a top bar with the project name and the signed-in person, and orange actions on a light canvas.

## Screens

| Screen | What it shows | Already stored | Later than the current build |
| --- | --- | --- | --- |
| 1. Dashboard | Welcome, module cards, project progress, recent activity | Modules, progress, audit | Welcome layout |
| 2. Overview | Description, goals, phase timeline, stakeholders, links | Health, notes, milestones, latest report, activity | Goals, phase dates, stakeholders |
| 3. Project plan | Timeline, list, and dependencies, with phase progress | Issue list, status, effort | Phase timeline, dependencies, add milestone |
| 4. Kanban | Task cards, filters, due dates, assignees | Status columns and status moves | Due dates, assignees, add task, search |
| 5. Documents | Library table with version and status | Upload, versions, recycle bin | Baselines tab, search |
| 6. Document detail | Preview plus version history | Download and new version | In-page preview |
| 7. Status reports | List of reports with period, status, and progress | Draft, review, approve, publish | List layout |
| 8. Status report detail | On track, key updates, upcoming focus | Report title and body | Phase progress beside the report |
| 9. Settings | People, email, role, and permission | Admin invite of an employee | Owner, Contributor, and Viewer roles |

The next visual pass applies the shared frame and the dashboard cards to the pages that already have data. Dependencies, baselines, in-page preview, phase dates, and the extra roles stay on their later releases.
